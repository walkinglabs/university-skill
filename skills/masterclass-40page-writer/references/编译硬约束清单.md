```bash
cd <文章目录> && /opt/homebrew/bin/tectonic -X compile <主文件>.tex --outdir . > /tmp/x.log 2>&1; echo "EXIT=$?"

# 致命错误
grep -E "Missing \\\$|Undefined control|! LaTeX|! Package|Giving up|unrecoverable|Runaway" /tmp/x.log | head -20

# 显著溢出（≥10pt；<10pt 可忽略）

```

**页数码**（PDF 用压缩对象流，grep 不到，须解压统计）：

```python
import re, zlib
data = open("<主文件>.pdf", "rb").read()
c = 0
for m in re.finditer(rb'stream\r?\n(.*?)\r?\nendstream', data, re.S):
    try: dec = zlib.decompress(m.group(1))
    except: continue
    if b'/Type' in dec and b'Page' in dec:
        c += len(re.findall(rb'/Type\s*/Page\b(?!s)', dec))
print("pages:", c)
```

## 一、致命级（XeTeX 崩溃，PDF 不产出）

| # | 坑 | 正确做法 |
|---|---|---|
| 1 | 数学符号裸用在中文正文（如「向量场`\approx`常数」「遗骸`\neq`终点」） | 必须包在 `$...$` 内。**这是最高频的致命错** |
| 2 | 文件名/代码标识符的**下划线**写在正文（如 `vla_flow_matching`） | `\texttt{vla\_flow\_matching}`；长词再加 `\-` 断点 |
| 3 | 伪代码命令包进 `tcolorbox` | 必须 `\begin{algorithm}` + `\begin{algorithmic}[1]`，盒子只能放算法**外面** |
| 4 | `algpseudocode` 用全大写 `algorithmic` 风格 | 用混合大小写：`\Require \Ensure \State \Repeat \Until \For \EndFor` |
| 5 | 用 `\TO` | 该包未定义，写 `\For{$i=0$ \textbf{to} $N-1$}` |
| 6 | 附录用 `\section*{附录…}` | 用 `\appendix`，其后 `\section` 自动变 A/B/C |
| 6a | `\item` 后\textbf{直接跟中文且无空格}（如 `\item门槛本身`） | LaTeX 会把整串吞成控制序列名，报 `Undefined control sequence` 并崩溃。\textbf{必须写 `\item 门槛本身`}（保留空格）。排查技巧：看报错行号附近的 `\item`，空格极易在长句改写中被吃掉 |
| 6b | `\permil` 生成千分号 | `ctexart` 下未定义。改用 `\usepackage{textcomp}` + `\textperthousand`，且要写在数学模式\textbf{外}：`$5.63$\,\textperthousand` |

## 二、溢出级（不致命，但文字冲出页面）

| # | 坑 | 正确做法 |
|---|---|---|
| 7 | 多行算式写进 `equation` | `equation` 不支持换行；改用 `align` + `\nonumber`（实测溢出 94pt） |
| 8 | 超长 `\texttt{...}` 无法断行 | 用 `\-` 插断点；**长 DOI/URL 直接用 `\href{https://doi.org/<DOI>}{\nolinkurl{<DOI>}}`** |
| 9 | 窄 `p{}` 列放长 DOI | DOI 列给到 **≥5.9cm**；换 `\nolinkurl` 后可从 27 处 Overfull 降到 6 处且全 <10pt |
| 10 | 表格总宽超版心 | 版心约 16cm。三列常用预算 `0.8 + 7.9 + 5.9 = 14.6cm`；四列预算 `1.4+5.6+1.4+5.6=14.0cm`。**列宽之外还要留 `\tabcolsep`（每列间约 0.2cm）** |

**表格溢出速修**：先把最宽的列缩 0.2--0.4cm，再看是否还报；不要一次性大改。

## 三、TikZ 级

| # | 坑 | 正确做法 |
|---|---|---|
| 11 | 并排子图用 `xshift` + 外层 `scale` | 两者复合会算错位置导致**图形重叠**；改为**同一坐标系叠加显示** |
| 12 | `\foreach` 配 `gray!55!white` / `above left=4pt` | 偶发 TikZ 解析失败；改用显式 `\draw` 序列 + `gray!50` / `above left` |
| 13 | 方框外单独定位标题文字 | 标题与正文写在**同一个 node 的 `{}` 内**，配 `text width` 防出界 |
| 14 | 节点坐标超出 ±5（x）/ ±3（y） | 配合 `scale=0.9` 控制，先估算总宽再落笔 |
| 15 | `decoration={snake, ...}` 画波浪线 | 需要 `decorations.pathmorphing` 库，本模板**未加载**，会报 `I do not know the key '/pgf/decoration/'` 并崩溃。**改用 `dashed`** |
| 15a | TikZ 节点内写 `①②③④⑤` 等带圈数字 | 节点默认字体是 `lmroman10-regular`，**无此字形**，报 `could not represent character` / `Missing character`，图上会缺字。**改用 `1 · 人口`、`2 · 债务` 这类 ASCII 前缀**（正文中可用，节点内不可用） |
| 15b | 六列表格列宽总和 $\ge 13.6\text{cm}$ | 六列时 `\tabcolsep` 合计约 $2.4\text{cm}$，加版心 $16\text{cm}$ 会溢出（实测 $14.6\text{cm}$ 列宽 $\rightarrow$ 溢出 $32\text{pt}$）。六列预算压到 $2.0+2.3+2.3+2.2+2.2+2.4=13.4\text{cm}$ |

## 五、追加（2026-08-28 第 6 篇实测）

- **中文正文里的数学符号仍是最常见的致命错**：如「遗骸 `\neq` 故事的终点」必须写成「遗骸 `$\neq$` 故事的终点」。
  写完后建议全局扫一遍确认都包在 `$...$` 内。
- **非理工/人文题材不要虚构 DOI**（详见 `prompt_主内容_v1_40page.md` 的追加章节）：中世纪原始史料与现代历史专著大多没有 DOI，
  附录 D 应改为「史料与现代研究导航」，给出编者/书名/年份与数字资源，并在正文开头声明。
