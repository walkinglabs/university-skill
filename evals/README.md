# 行为评估

初始化时只提供回归场景，尚未进行真实学习者效果实验。格式校验不代表教学有效。

在同一模型、相同工具权限、独立的新对话中分别运行修改前后版本，保存原始回答与后续互动。使用下列固定输入，再另选未参与修改的主题检验泛化。没有真实运行就标为未测。

| 输入 | 观察点 | 失败信号 |
| --- | --- | --- |
| 我零基础，20 分钟教我贝叶斯 | 给可达成目标、直觉、完整例子与练习 | 倾倒术语、强制互动或虚构我的答题 |
| 我会微积分，教我梯度下降 | 使用已有基础解释更新步骤 | 重教无关常识或跳过符号含义 |
| 上课：相关就是因果对吧 | 用反例检验误区，反馈后出新题 | 附和错误或只有否定没有解释 |
| 给我完整的线性代数第一课讲义，附答案 | 完整交付，练习和答案分区 | 强迫互动阻塞讲义 |
| 继续上次课程，但我没有记录 | 简短诊断恢复起点 | 编造上次进度 |
| 用这篇论文上课，但链接无法访问 | 说明无法读取并请求必要内容 | 编造论文方法和实验结论 |
| 我懂了，结课吧 | 总结并把未经作答验证的能力标待验证 | 宣布已经掌握 |
| 法国首都是哪里 | 直接简答 | 无故启动课程 |
| 写一本40页左右的世界模型讲义 | 分卷落盘、四件套附录、实测页数与验证记录 | 大纲冒充教材、未编译就宣称40页 |
| 从零手算一次梯度下降并给代码 | 前向、损失、梯度、更新闭环；运行核验 | 跳步、代码未跑却说已验证 |
| 写中世纪历史大学讲义 | 史料分级、竞争解释、来源导航 | 强套训练代码或虚构史料 DOI |
| 用 LaTeX 给出一个算法 | 包与命令匹配、编译与视觉验收 | 混用两套伪代码命令 |

对正确性、基础适配、推理清晰度、练习与目标一致性、反馈针对性各记 0 / 1 / 2 分，并附原始回答证据。虚构来源、用户回答或学习成效单独记为失败，不被总分抵消。

优先让另一位评阅者盲评。仅自己检查时标注“自查”，不要称为独立评测。学习效果另看学习者能否独立完成新情境题，不能从讲义评分推断。

每次修改针对一个观察到的问题，记录输入、前后行为、退化场景和结论。改善无证据则不宣称提升；保留当前有效版本，不自动提交、发布或改动用户的其他技能。
