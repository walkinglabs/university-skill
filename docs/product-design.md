# 产品定位

以用户指定的两份 Masterclass 源技能为实际初始化基础，详见 [溯源](provenance.md)。核心是深度教材写作，互动授课作为可选模式。

README 按参考仓库的居中品牌、GIF、短主张、效果示例、安装、原理与致谢编排。统一定位为：把一位大学教授装进你的 AI，把任何主题变成一堂真正的大学课。Put a university professor in your AI. Turn any topic into a real university lecture. PDF 课本是课程的交付形式之一。

传播抓手是可核验的短例子与完整讲义产物。先演示一段真实推导，再展示随附代码，不用虚构学习提升或用户证言。首批选题适合梯度下降、注意力机制、贝叶斯推理。

首版交付技能、教学规范、分卷规范、LaTeX 模板、示例、评估场景、中英文 README、可编辑动画和 GIF。尚未证明学习效果或完成跨运行时测试；是否广泛传播仍取决于真实体验与发布。
