# 从一个参数理解梯度下降

这是设计示例，数值由 [随附脚本](gradient_descent.py) 验证。目标是解释更新方向，并计算一次更新。以下数字为教学假设值。

## 为什么需要更新

用 ŷ = wx 预测一个量。给定 x = 2、目标 y = 6，初始 w = 1 时预测为 2，偏小。这个例子能直接解出 w = 3；先用它理解更新，再把更新方法用于不能直接求解的复杂模型。

选择损失 L(w) = ½(wx − y)²。平方使正负误差都产生惩罚，前面的 ½ 只是让导数更简洁。

## 斜率如何给方向

代入这组数据，L(w) = ½(2w − 6)² = 2w² − 12w + 18。
若尚未学过导数，先看变化量：

L(w + h) − L(w) = (4w − 12)h + 2h²。

除以 h，再让 h 趋近 0，得到局部斜率 4w − 12。在 w = 1 处斜率是 −8，表示稍微增大 w 会让损失下降。因此更新沿斜率的反方向，写为 w新 = w旧 − η × 斜率，η 是步长。

## 完整计算

| 步骤 | 代入 | 结果 |
| --- | --- | ---: |
| 预测 | 1 × 2 | 2 |
| 误差 | 2 − 6 | −4 |
| 损失 | ½ × (−4)² | 8 |
| 梯度 | (2 − 6) × 2 | −8 |
| 更新 | 1 − 0.1 × (−8) | 1.8 |
| 新预测 | 1.8 × 2 | 3.6 |
| 新损失 | ½ × (3.6 − 6)² | 2.88 |

这只是下降了一步，没有到达最小值。

## 步长的边界

取 η = 0.6，同样从 w = 1 出发，得到 w新 = 5.8，新损失为 15.68，反而高于原来的 8。

更一般地，w新 − 3 = (1 − 4η)(w旧 − 3)。要让距最优点的误差每次缩小，需要 |1 − 4η| < 1，即 0 < η < 0.5。这个界限来自本例的二次函数，不能直接套到任意神经网络。

## 实现

运行：

```bash
python3 examples/gradient_descent.py
```

脚本先计算预测与误差，用误差乘输入得到梯度，随后更新参数并重新计算损失。断言核对两个步长，有限差分独立检查梯度。

## 自测

从 w = 1、η = 0.2 开始计算。新参数与损失是多少？为什么不能因为 η = 0.1 有效，就推断步长越大越好？
